# 0035. Licencias: código MIT, contenido con todos los derechos reservados

- **Estado:** aceptada
- **Fecha:** 2026-11-24
- **Requerimientos:** RT §4.2

## Contexto

Hacía falta separar la licencia del software de la de la obra.

## Decisión

El código usa la licencia MIT. El contenido tiene todos los derechos reservados por defecto, con un campo `license` por pieza para abrir algunas (por ejemplo CC BY-NC-ND) si la Fundación lo decide.

## Por qué

Permite reutilizar el software y protege la obra.

## Alternativas descartadas

Todo bajo una licencia abierta, o todo cerrado.
