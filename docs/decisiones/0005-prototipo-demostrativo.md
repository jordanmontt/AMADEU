# 0005. El prototipo también es una demostración para financiadores

- **Estado:** aceptada
- **Fecha:** 2026-11-24
- **Requerimientos:** RF-03, RF-11, RF-62

## Contexto

El proyecto busca más financiamiento cuando haya un prototipo funcional.

## Decisión

Se diseña para impresionar: portada de alto impacto, la experiencia completa de *Sangre y Sueño* y las obras futuras visibles como «próximamente». Las estadísticas tienen un panel público.

## Por qué

Muestra el potencial del proyecto completo y deja evidencia de uso.

## Alternativas descartadas

Un prototipo mínimo sin diseño propio.
