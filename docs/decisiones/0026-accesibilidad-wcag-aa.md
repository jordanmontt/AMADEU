# 0026. Accesibilidad WCAG 2.2 AA

- **Estado:** aceptada
- **Fecha:** 2026-11-24
- **Requerimientos:** RF-56, RT-42

## Contexto

Se busca calidad y acceso a fondos institucionales.

## Decisión

WCAG 2.2 AA es requisito: `alt` obligatorio, teclado, contraste, `prefers-reduced-motion` y transcripciones cuando existan.

## Por qué

Hace el archivo inclusivo y suele ser requisito de las instituciones.

## Alternativas descartadas

Accesibilidad sin un objetivo formal.
