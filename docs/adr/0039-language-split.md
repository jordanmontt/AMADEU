# 0039. Foundation-facing docs in Spanish; everything technical in English

- **Status:** Accepted; supersedes [0027](0027-documentation-language.md)
- **Date:** 2026-11-24
- **Requirements:** RT-14

## Context

Another engineer may take over the code later. Technical knowledge must be accessible to any engineer.

## Decision

**Spanish:** functional requirements, the archive inventory, the general README, the site UI, admin labels and public URLs. **English:** technical requirements, architecture, ADRs, `AGENTS.md`, `CONTRIBUTING.md`, `GLOSSARY.md`, code, comments, tests and commit messages.

## Consequences

The Foundation reads what concerns it; any engineer can take over the technical side.

## Rejected alternatives

Everything in Spanish (0027); everything in English (the Foundation could not read the requirements).
