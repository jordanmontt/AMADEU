# 0013. Visible archival record based on Dublin Core

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RF-40, RF-41, RT §4.3

## Context

A digital archive must be citable and rigorous, not just a gallery.

## Decision

Every item has a visible record with fields mapped to Dublin Core, plus schema.org JSON-LD.

## Consequences

A standard recognized by libraries and archives; helps with institutions and search engines.

## Rejected alternatives

Title and description only.
