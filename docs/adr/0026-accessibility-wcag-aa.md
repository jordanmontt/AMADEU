# 0026. Accessibility: WCAG 2.2 AA

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RF-56, RT-42

## Context

Quality and access to institutional funding.

## Decision

WCAG 2.2 AA is a requirement: mandatory `alt`, keyboard access, contrast, `prefers-reduced-motion`, transcripts where available. Automated checks with axe in E2E tests.

## Consequences

Inclusive archive; often required by institutions.

## Rejected alternatives

Accessibility without a formal target.
