# 0003. Transcribed text first, facsimile optional

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RF-16, RF-20

## Context

Books can be shown as text or as scanned pages. The archive has extractable digital text (Tomo I, 2012) but no scan of the 1981 edition.

## Decision

The transcribed text is the primary reading experience. A facsimile is shown when a scan exists.

## Consequences

Text is readable on phones, searchable, accessible and light; the facsimile adds archival value.

## Rejected alternatives

Facsimile only; text only.
