# 0007. Spanish-only UI in v1, ready for English

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RF-55, RT-43

## Context

Marcelo lived in the US and there may be an English-speaking audience, but translation doubles content work.

## Decision

Content and UI are Spanish. UI strings are centralized so English can be added later without a rewrite.

## Consequences

Ships faster without closing the door to translation.

## Rejected alternatives

Bilingual from day one.
