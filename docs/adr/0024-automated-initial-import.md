# 0024. Automated initial import; the Foundation curates

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RF-59, RT §10

## Context

The raw archive (81 MP3s, 58 images, PDFs) must become structured entries.

## Decision

The developer writes scripts that extract text, upload media and generate the *Sangre y Sueño* entries. The Foundation completes and corrects records from the admin (inventory codes, relations, duplicates).

## Consequences

Automation for the repetitive work; curatorial knowledge stays with the Foundation.

## Rejected alternatives

Fully manual entry by the Foundation; full curation by the developer.
