# 0035. Licences: MIT for code, all rights reserved for content

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RT §4.2

## Context

Software and artwork need separate licences.

## Decision

Code is MIT. Content is all rights reserved by default, with a per-item `license` field to open some items (e.g. CC BY-NC-ND) if the Foundation decides to.

## Consequences

Software can be reused; the work stays protected.

## Rejected alternatives

Everything under an open licence; everything closed.
