# 0027. Documentation in Spanish, code in English

- **Status:** Superseded by [0039](0039-language-split.md)
- **Date:** 2026-11-24
- **Requirements:** RT-14

## Context

The language of documentation, code, schema and URLs had to be defined.

## Decision

All documents in Spanish (`docs/`, ADR format). Code, schema field names and folders in English. UI, admin labels and URLs in Spanish. TypeScript.

## Consequences

Readable by the Foundation and funders; code follows common conventions.

## Rejected alternatives

Everything in Spanish or everything in English.
