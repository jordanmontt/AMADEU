# 0043. Architecture documented with arc42 and C4 (Mermaid)

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** —

## Context

Architecture must be understandable without the original developer.

## Decision

`docs/architecture.md` follows a reduced **arc42** template with **C4** diagrams written in Mermaid (rendered by GitHub). Plus `CONTRIBUTING.md` (setup, testing, publishing, adding a collection) and `GLOSSARY.md` (project terms).

## Consequences

Recognized formats; diagrams live as text next to the code and are reviewed like code.

## Rejected alternatives

Free-form notes; diagrams in external tools.
