# 0020. Accounts owned by the Foundation (except the repository, for now)

- **Status:** Accepted
- **Date:** 2026-11-24
- **Requirements:** RT §11

## Context

The proposal requires the domain, hosting and credentials to belong to the Foundation.

## Decision

Cloudflare, YouTube, Internet Archive and GoatCounter are created with the Foundation's email; the developer is invited as administrator. The GitHub repository stays under the developer's account for now.

## Consequences

Institutional continuity without slowing development.

## Rejected alternatives

Everything in the developer's name.
