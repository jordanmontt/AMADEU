## Convenciones

- La documentación se escribe en **español**.
- El código, los nombres de campos del esquema y los nombres de carpetas de contenido van en **inglés**.
- La interfaz del sitio, las etiquetas del admin y las URLs públicas van en **español**.
- Los requerimientos tienen identificadores (`RF-…` funcionales, `RT-…` técnicos) para poder citarlos en issues y commits.
- Cuando cambie una decisión, se escribe una decisión nueva que reemplaza a la anterior. La anterior se marca como «Reemplazada por …» y no se borra.

## Fuentes de contexto (fuera del repo)

La carpeta padre del repo tiene material de referencia que **no** se versiona:

- `Requerimientos/Propuesta de contenidos de la aplicación.pdf`: la propuesta original para la Fundación.
- `Archivos Digitales/`: el archivo digitalizado, unos 6,6 GB descomprimidos.
- `Logos/`: los logos actuales, que solo existen como fotos de WhatsApp.
