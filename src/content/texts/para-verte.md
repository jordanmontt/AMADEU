Trepo las cuestas callado, para verte.
Mi corazón se prepara, para verte.
Ya estoy llegando a la altura, nieve y cielo,
cóndor blanco, para verte.
Para que limpies mi pena con tu vuelo
majestuoso, transparente.

Alas de nieve quemante, para verte.
Rosa, cristal transparente, para verte.
Helado espejo de mi alma, para verte.
Padre eterno de mi padre,
padre eterno de mi padre,
padre eterno de mi padre, para verte.

Guerrero resplandeciente, para verte.
Diamante del horizonte, para verte.
Vengo a dejar una ofrenda de silencio,
de amargura, de tristeza.
Para que llenes mi alma de misterio,
de blancura, de belleza.
Fantasma de roca y niebla, para verte.
Monarca de las pasiones, para verte.
Tejido de nieve y plata, para verte.
Padre eterno de mi padre,
padre eterno de mi padre,
padre eterno de mi padre, para verte.
